# channel-flow-bot

Telegram-бот, який сам виставляє в канал послідовність: розігрів → розігрів → пост → нагадування…
Пауза між кроками 2 хв, нагадування видаляються з каналу через 2 хв, чергу можна редагувати наживо.

## Змінні Railway
BOT_TOKEN, ADMIN_ID, DATABASE_URL (`${{Postgres.DATABASE_URL}}`), необов'язково CHANNEL_ID, TIMEZONE.

Запуск: `python bot.py`. Бот має бути адміном каналу з правами публікувати й видаляти повідомлення.
